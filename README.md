# 雅思英式听力单词训练器

这是一个本地运行的雅思听力练习小工具。你输入单词后，页面会用英式发音朗读单词，并自动生成一句英文例句继续朗读，然后让你从多个选项中选择刚刚听到的单词。

项目主要用于训练 IELTS Listening 中对英式发音、单词音形对应和短句语境的反应速度。

## 主要功能

- 支持每行输入一个单词。
- 支持用逗号、中文逗号、分号分隔多个单词。
- 不需要手动写例句，系统会自动生成 IELTS 风格英文例句。
- 使用 Windows 已安装的 `English (United Kingdom)` 文本转语音。
- 朗读过程中可以提前点击答案。
- 答对后会自动停止当前朗读并进入下一题。
- 支持 3、4、5、6 个选项。
- 支持调整朗读语速。
- 全部在本地运行，不需要上传单词到服务器。

## 启动方式

双击项目目录中的：

```text
启动雅思训练器.bat
```

启动后浏览器会打开：

```text
http://127.0.0.1:8765/index.html
```

使用时请保持启动窗口打开。关闭窗口后，本地服务会停止，网页也会无法访问。

## 输入格式

推荐每行一个单词：

```text
accommodation
evidence
significant
maintenance
```

也可以一行输入多个单词：

```text
accommodation, evidence, significant, maintenance
```

页面会自动为每个单词生成例句。

## 英式发音要求

本工具需要 Windows 安装英式文本转语音语音包。

安装路径通常是：

```text
Windows 设置 -> 时间和语言 -> 语音 -> 管理语音 / 添加语音
```

选择并安装：

```text
English (United Kingdom)
```

安装完成后，如果页面仍然没有识别到英式语音，请重启浏览器；必要时重启 Windows。

## 文件说明

- `index.html`：页面结构。
- `styles.css`：页面样式。
- `app.js`：训练逻辑，包括出题、答题、计分和自动跳题。
- `serve-ielts.ps1`：本地静态服务，同时调用 Windows 英式 TTS 生成朗读音频。
- `启动雅思训练器.bat`：一键启动脚本。

## 注意

这个项目是为个人学习雅思听力准备的本地工具。它不会把你的单词列表上传到外部服务器，朗读音频由本机 Windows 语音功能生成。
