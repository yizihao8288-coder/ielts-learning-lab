# IELTS Learning Lab 中文说明

> 我先做了一个自己真会用的 IELTS 词汇训练器，后来又从里面发现了一个值得研究的问题。

[直接打开在线版](https://yizihao8288-coder.github.io/ielts-learning-lab/demo/) · [看看研究做到哪了](https://yizihao8288-coder.github.io/ielts-learning-lab/results/) · [English README](README.md)

## 它不是从“我要做个项目”开始的

我在准备 IELTS、背单词和整理机考错题时，能找到很多词表，却很难找到一个符合自己复习习惯的工具：先听，再拼写，放回语境里读，把没掌握的留下，之后只复习真正容易错的部分。

所以我先把这个学习闭环做了出来。现在它包括听力、填空、阅读、写作、收藏、错题复习、导入导出、本地保存和浏览器朗读。老师不需要注册账号，也不需要 API Key，点开网页就能用。

后来我尝试自动生成释义和例句，遇到了一个比“功能能不能运行”更有意思的问题：模型可以给出格式完全正确的 JSON，但内容仍然不适合学习。例如目标词被换掉了、中文释义里没有中文，或者例句根本没有使用要学习的短语。

于是这个项目有了两个彼此相连的部分：

- 前半部分是我会实际使用的训练工具；
- 后半部分研究怎样让自动生成的词汇条目不只“格式正确”，还更接近“可以直接拿来学”。

## 老师可以怎么试

最快的方法是打开[在线演示](https://yizihao8288-coder.github.io/ielts-learning-lab/demo/)。它完全在浏览器里运行，不安装软件，也不会调用模型。

如果想在本地运行：

- Windows 安装 Python 3.10+ 后，双击 `启动雅思训练器.bat`；
- macOS 或 Linux 执行 `python3 run.py`。

核心训练功能不需要安装第三方 Python 包。可选的在线生成功能失败时，会自动回到本地词典，不会打断练习。

## 我真正想验证什么

同一个单词分别使用三种生成方式：

1. 只在提示词里要求返回 JSON；
2. 使用严格 JSON Schema；
3. 使用严格 Schema，再做语义检查，失败时根据具体原因最多修复一次。

这里最重要的区别是：Schema 主要回答“格式对不对”，语义验证继续追问“内容能不能学”。检查内容包括目标词是否一致、中文释义是否真的含中文、例句是否包含完整词或短语、句长是否合理，以及有没有占位符、元话术或重复内容。

## 现在做到哪了

生成、验证、失败降级和 12 项自动测试已经完成。计划中的 100 词正式比较和人工盲评还没有执行，因此这里不会提前放一张看起来很漂亮但没有数据依据的结果图。[研究状态页](https://yizihao8288-coder.github.io/ielts-learning-lab/results/)列出了目前真实存在的证据，完整方法见 [`docs/research-protocol.md`](docs/research-protocol.md)。

## 初学者最值得理解的三件事

1. `run.py` 是本地服务器，负责安全保存和可选 API；没有它，网页的核心训练功能仍然可以运行。
2. JSON Schema 只能约束数据结构，不能保证释义正确、例句自然，所以还需要语义规则和人工评价。
3. 测试通过只说明已经检查的程序行为符合预期，不能直接推出“这个方法一定提升学习效果”。
